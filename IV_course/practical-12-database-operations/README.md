# Практична робота №12. Робота з базою даних у C#

- Мова програмування: C#
- Технологія: Windows Forms (.NET 8.0)
- Середовище розробки: Visual Studio Community 2022
- СУБД: PostgreSQL
- Доступ до даних: ADO.NET, Npgsql

## Мета роботи

Навчитися керувати даними за допомогою SQL-запитів та відображати результати у Windows Forms.

## Завдання

- Створити інтерфейс із `TabControl` та кількома вкладками `TabPage`.
- На одній вкладці розмістити `DataGridView` для роботи з базою даних.
- На іншій вкладці розмістити `Chart`.
- Наповнити таблицю щонайменше 30 унікальними записами.
- Реалізувати щонайменше три типи запитів, включно з вибіркою за умовою.
- Реалізувати видалення записів за умовою.
- Побудувати діаграму за даними таблиці.

## Особливості реалізації

Використовується база даних PostgreSQL, створена у практичній роботі №11, та провайдер Npgsql замість OleDb.
